# 产品愿景与定位

> 本文档是所有设计文档的上游。路线图见 [roadmap.md](roadmap.md)，具体设计见 [design-context.md](design-context.md)、[design-growth.md](design-growth.md)、[design-knowledge.md](design-knowledge.md)。

## 一句话定位

> **Reflector 是一面诚实的镜子：它记得你真实的言行，并帮你从中看见自己。**

Reflector 不是录音工具、不是笔记软件、不是习惯打卡 App——这些都只是输入或形态。产品的本体是「**基于真实证据的自我认知系统**」。

录音、位置、说话人识别、知识库、AI 教练，全部服务于同一件事：让你看见**真实的自己**——你实际说了什么、对谁说的、在什么情绪下说的、说过的话兑现了多少——而不是你以为的自己。

## 为什么这个产品该存在（关键洞察）

### 1. 自我报告是有偏的

所有成长类产品（日记、习惯、目标 App）都建立在用户的**自我报告**之上，而心理学反复证明：人对自己的记忆和叙述是系统性失真的——我们美化动机、淡化冲突、高估投入。

Reflector 的不公平优势：它拥有的不是你的回忆，而是**客观证据**——你实际说过的话（转写）、实际见的人（声纹）、实际去的地方（位置）、实际许下的承诺（commitments）。当 AI 说"本周你打断他人 8 次"，这不是猜测，是可点开验证的事实。

### 2. 反思是反人性的，但被好问题触发是自然的

几乎没人能坚持写日记——空白页面前的输出负担太重。但几乎每个人都会回答一个切中要害的问题：

> "张三提出风险时你立刻反驳，当时你在担心什么？"

产品要做的不是逼用户输出，而是**用证据生成好问题**。输入是被动采集的（录音、位置），输出是被好问题引导的（日报中的反思提问）。用户唯一需要的习惯是：按下录音键，晚上读一份日报。

### 3. 数据复利

单条记录的价值很低，但跨月、跨年的模式只有在积累中才显现：你的情绪触发器是谁、哪段关系在变冷、你的承诺兑现率、你高效时段的规律。资产层（[design-knowledge.md](design-knowledge.md)）的存在意义就是让数据随时间**增值**而非沉没——这也是用户长期留下来的根本理由。

## 目标用户

主动寻求成长的「自我审视者」：

- 想提升沟通与领导力的**管理者**
- 处在面试、转型、创业等高密度对话期的人
- 有教练/心理咨询习惯、相信"被看见"价值的人

策略：先自用（single-user）打磨价值密度，不为规模化稀释定位。一个用户每天愿意读完日报，胜过一万个注册即流失的用户。

## 差异化（vs 邻近产品）

| 邻近产品 | 它们做的 | Reflector 的不同 |
|---|---|---|
| Otter / 飞书妙记 | 会议纪要，服务**工作产出** | 服务**你这个人**——分析的是你，不是会议 |
| Notion / Obsidian | 你主动写，才有数据 | 被动采集真实言行，无输入负担 |
| 习惯 / 目标 App | 自我报告 + 游戏化激励 | 用客观证据对照"你说的"与"你做的" |
| AI 聊天助手 | 通用知识，每次从零认识你 | 见证过你全部历史的教练，问题带着证据 |

这四类产品都做不了的事：**指着你三周前的原话，问你一个只有你能回答的问题。**

## 产品原则

这些原则是功能取舍的依据，冲突时按序优先：

1. **证据先于观点**。每条 AI 洞察必须可回溯到原始记录（evidence 引用，用户可点开验证）。宁可少说，不可编造；无召回就承认"没有找到"。
2. **提问先于答案**。镜子不教训人，只让你看清。苏格拉底式提问优先于直接建议；教练引用事实，结论留给用户。
3. **平静技术**。无 streak 羞辱、无徽章、无 push 轰炸。每天一份日报、几个好问题，仅此而已。反思需要的是安静，不是 engagement。
4. **数据是用户的资产**。一键全量导出（`/export`）、删除即彻底、音频转写后即删、本地优先处理。隐私不是合规负担，而是定位本身——镜子必须是私密的，否则没人敢在它面前真实。
5. **长期复利**。每个新功能都要回答："一年后，它让用户的数据更值钱了吗？"答案是否的功能（即便短期吸引人）不做。

## 北极星指标

**每周「被看见时刻」数**——用户确认"这个洞察说中了我"的次数（日报中点"准"、回应反思问题、教练对话中的确认）。

**反指标**（刻意不优化）：录音时长、App 打开次数、消息推送点击率。采集量不是价值，洞察命中才是。

### 阶段目标

| 阶段 | 验证的问题 |
|---|---|
| M2–M3 | "日报值得每天读吗？"——情境化数据 + 每日反思的洞察命中率 |
| M3 | "数据在变成资产吗？"——检索/导出被真实使用；收藏的知识开始被复习而非沉没 |
| M4 | "教练比朋友更懂我吗？"——基于全量历史的对话能否产生朋友给不了的问题 |
| M4 | "学的东西用出来了吗？"——练习意图与应用检测能否在真实对话中验证行为改变（[design-learning.md](design-learning.md)） |

## 非目标（明确不做）

- **不做会议效率工具**：不做纪要分发、待办协作、团队空间。那是 Otter 的战场，且会把定位拖回"工具"。
- **不做社交/分享**：镜子是私密的。没有动态、没有关注、没有"分享你的反思"。
- **不做量化自我仪表盘**：图表堆砌不等于自我认知。可视化只在服务于具体洞察时出现（如情绪曲线关联触发因素）。
- **不做通用第二大脑**：知识库（assets）服务于成长闭环，不追求 PKM 全功能（双链画布、插件生态等）。

## 愿景与路线图的映射

| 里程碑 | 在愿景中的角色 |
|---|---|
| M1 录音管线（已完成） | 镜子的玻璃：把言行变成可分析的文本 |
| M2 情境化（何人/何时/何地） | 镜子的清晰度：从"有人说了话"到"你对张三说了这些" |
| M3 成长闭环 + 资产层 | 镜子开始说话：日报、好问题、承诺对照；数据开始复利；知识进入复习内化 |
| M4 教练 / 学习闭环 / 图谱 | 镜子成为伙伴与陪练：见证你全部历史的对话者，并在真实场景中检验你学的东西用出来了没（[design-learning.md](design-learning.md)） |
